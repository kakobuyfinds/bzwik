How to use the KakoBuy spreadsheet

Keep the seller link, selected size, price and shipping quote together so you can compare options before paying.

  1. Confirm the exact listing

    Open the item on CAFANS. Find the original marketplace listing and check its color, size and stock. If KakoBuy is available for that item, follow the agent option or paste the seller link into the agent’s search field.

  2. Compare measurements

    For tees and sweatshirts, compare chest width and body length against a garment you own. For shoes, confirm whether the size chart uses foot length or insole length.

  3. Review warehouse photos

    If the agent offers QC photos, check the size tag, color and relevant measurements. Request a close-up if a detail is unclear and check the return window before approving shipment.

  4. Estimate the delivered cost

    Add the item price, any domestic delivery and agent fees, the international shipping quote and any applicable import charges. Compare shipping lines using the same destination and parcel dimensions.

Frequently asked questions

What is this KakoBuy spreadsheet?

It is an independent shopping guide and a searchable selection of CAFANS listings. The product links open on CAFANS, where you can review details and available shopping-agent options.

Does the listed price include international shipping?

The catalog shows estimated item prices in USD. Check the agent’s current quote for shipping and fees using your destination and parcel details.

What if a product link stops working?

Open the matching CAFANS category and search for the product name or a similar item. Verify the current seller link and selected variant before placing an order.
